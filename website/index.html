Install Warden

  1. Open the downloaded .dmg file.
  2. Drag Warden into Applications, then open the app.
  3. Follow the interactive guide. You can return to it from the lantern in your menu bar.

Opening the beta for the first time

This beta is not yet notarized by Apple. After you try to open it, macOS may ask you to go to System Settings → Privacy & Security → Open Anyway.

Read Apple’s instructions

Included in this version

An interactive guide, session alerts, usage history and train-guard for supervising long-running jobs. Install train-guard from the app without installing Python.

Session monitoring and history stay on your Mac. Phone access works on the same local network.

To select the right integrated terminal in VS Code, install the optional companion using “Install from VSIX…”.
